# Prior-art scan: markets and competitions for verifiable useful-work ML research (as of 2026-11-05)

Scope: projects that overlap with the planned D-PoDL revival. In that design, miners (humans or AI agents) submit recipe diffs, model or adapter deltas, or pseudo-gradients against a frozen recipe or base. Validators re-measure each submission with a frozen multi-seed verifier. Settlement runs on an existing L2 with commit-reveal, stake, a challenge window with bisection, slashing, and lineage royalties. The flagship is a "verifiable autoresearch" market.

Source tags: **[P]** = primary (project's own repo, docs, paper or blog); **[S]** = secondary (news, aggregators, third-party summaries). **[HYPE]** = a self-reported or promotional claim with no independent check. Every date is the date of the source or of the event. "Checked" means fetched or searched in this session (2026-11-05). The GitHub API was not used; repo facts come from the rendered GitHub pages.

Earlier notes already cover Templar/Covenant-72B Gauntlet, IOTA SN9, Psyche, Pluralis Agora, Gensyn Verde/Delphi as a business, and Prime Intellect's frontier-automated-speedrun ([research_notes/DPoDL revival research November 2026/](../DPoDL%20revival%20research%20November%202026/)). They appear here only where they bear on competitive overlap.

## Q1. Bittensor subnets (Nov 2026) that reward ML research, recipe improvements or agent-written code

### Takeaway
Bittensor already runs three of our mechanism's pieces in production, each in a different subnet. Gradients SN56 pays for training-recipe repos and requires a statistical margin. Templar Crusades paid for training-code diffs, with commit-reveal, 3-run medians and weight verification. Teutonic SN3 pays for checkpoint improvements under a bootstrap lower-confidence-bound test, with a 5-king reward window that is a crude lineage royalty. None of them combines these pieces. None has slashing, a challenge or bisection window, or recursive lineage royalties, and none is a generic "autoresearch" market. Searches found no Bittensor subnet branded "autoresearch", "speedrun", "kernel optimization" or "AlphaEvolve-style".

### Cited Findings

**Teutonic (SN3, successor to Templar on netuid 3). Closest Bittensor analogue for the model-delta track.**
- [P, 2026] Teutonic-I 10B ran from 2026-06-02 to 2026-08-10. It is king-of-the-hill: miners take the current best checkpoint (the king), train a same-architecture challenger with any script, data or hardware, and submit it. The evaluation data is derived from the submission block's hash and the current data mix, so miners can't choose it. King and challenger are scored on identical 2,048-token sequences. — [Teutonic blog](https://blog.teutonic.ai/); [Teutonic-I technical report](https://teutonic.ai/paper.html)
- [P] Acceptance uses a per-sequence loss advantage, a percentile bootstrap with 10,000 resamples, and a lower confidence bound at α = 0.001 above δ = 0.0015 nats/token. — [Teutonic blog](https://blog.teutonic.ai/)
- [P] **Reward = current king plus up to 4 previous kings, 20% each** while their hotkeys stay registered. This is a short, fixed-depth "lineage" payout, not royalties proportional to contribution. — [Teutonic blog](https://blog.teutonic.ai/)
- [P] The competition ran 2,163 duels with 203 coronations (9.3% acceptance). The best king was #191, on day 60. Teutonic-I 10B averaged 62.28% over 11 benchmarks, against 57.55% for Covenant-72B and 59.78% for Quasar-Preview 18B; MMLU was 75.29%. The team is Jacob Steeves ("const") and Dendrite Quantum. The code is at github.com/unarbos/teutonic; no license is stated on the blog. — [Teutonic blog](https://blog.teutonic.ai/)
- [P] The blog mentions "various attempts to copy models". It describes no commit-reveal or checkpoint-hash scheme beyond using the block hash to pick evaluation data. — [Teutonic blog](https://blog.teutonic.ai/)
- [S, 2026-08-24] Teutonic-II, a 110B sparse MoE based on MiMoV2, was announced as a "loss based market" that pays for updates from "any compute, any individual, any algorithm". Const says rewards run "north of 6k USD per day for updates" [HYPE: depends on alpha price]. The promotion threshold was lowered from 0.0025 to 0.0015 on 2026-07-21. No Teutonic-II results had been reported as of the article. — [tao.media](https://www.tao.media/const-launches-teutonic-ii-110b-permissionless-training-run-on-bittensor-subnet-3/)
- [S, 2026-04 to 05] Earlier plans conflicted: a 1T-parameter run (BlockEden, 2026-04-22), a 24B looped transformer (TAO Daily) and an 80B run (2026-05-11). Plans clearly changed over time. — [BlockEden](https://blockeden.xyz/blog/2026/04/22/bittensor-sn3-teutonic-1-trillion-parameter-decentralized-llm-training-may-2026/); [TAO Daily](https://taodaily.io/teutonic-sn3-is-cooking-a-24b-looped-transformer-thats-a-bigger-deal-than-it-sounds/); [tao.media](https://www.tao.media/teutonic-subnet-begins-training-80b-ai-model-on-bittensor-marking-largest-decentralized-training-run-yet/)
- Status: **mainnet, live**. Teutonic-I is complete; Teutonic-II has been in progress since 2026-08.

**Templar "Crusades" (formerly SN3; now under Covenant AI). Closest Bittensor analogue for the training-code-diff track.**
- [P, repo checked 2026-11-05] Miners submit a single `train.py` (functions `inner_steps()` and `get_strategy()`) by URL. The URL is posted with **`set_reveal_commitment` (timelock-encrypted commit-reveal)**, and validators read it after `reveal_blocks`. Validators run it in a Docker `templar-eval` container through a security scan, a reference baseline, warmup, a timed eval, **final-weight verification against a reference run**, and MFU calculation. There are **3 evaluation runs and the median is used**. The default model is Qwen2.5-3B on 2×GPU; some sections say 7B. A static scanner blocks monkey-patching and timer tampering. Miners must train all parameters and process all tokens. Weights are set from median MFU. — [one-covenant/crusades](https://github.com/one-covenant/crusades)
- [P] The repo has 7 stars, 9 forks and 88 commits, with a 2026 copyright. The license was not visible. No lineage or attribution to earlier winners is described. — [one-covenant/crusades](https://github.com/one-covenant/crusades)
- [S] The metric is described inconsistently: the repo says MFU, while DeepWiki says tokens/s. A repost claims miners took a 7B model on 4×A100 from 66% to 74.5% MFU [HYPE: unverified]. — [deepwiki](https://deepwiki.com/one-covenant/crusades); [search summary of Templar posts](https://x.com/tplr_ai)
- [S, 2026-04-09/10] Covenant AI (Templar SN3, Basilica SN39, Grail SN81) left Bittensor over a governance dispute with Steeves, and TAO fell between about 9% and about 30% depending on the source. Crusades "lives in the one-covenant GitHub org", but post-exit status is unclear. Netuid 3 is now Teutonic, so **Crusades is likely dormant or relocated** (inference). — [tao.media](https://www.tao.media/covenant-ais-bittensor-exit-what-happened-how-bittensor-responded-and-whats-next-for-the-network/); [ownyourmind](https://ownyourmind.ai/tokenomics/templar-bittensor-covenant-exit/); [BeInCrypto](https://beincrypto.com/bittensor-tao-drops-covenant-ai-exits/)
- Conflict: the Templar repo README (prior notes) says "SN3 now runs Crusades", which contradicts SN3 = Teutonic from mid-April 2026. The README is probably stale. — [one-covenant/templar](https://github.com/one-covenant/templar)

**Gradients (SN56). Closest Bittensor analogue for paying for training recipes.**
- [S, aggregator citing project] Miners submit **AutoML training repos**, which validators clone at a pinned commit and run on validator-controlled GPUs, scoring the result on held-out data. Tournaments go through group, knockout and "boss" rounds. The boss round has 6 tasks decided **sample by sample with a 99% bootstrap test**, and the challenger must win at least 5. Entry costs 0.7 TAO (text) or 0.4 TAO (image), one entry per coldkey, and **fees buy back and burn SN56 alpha**. Emissions go roughly 76/19/5 to the top 3, plus participants. **Winning repos are published at github.com/gradients-opensource.** Key dates: 2025-07 Gradients 5.0 open-source tournaments; 2026-01, 2026-04 and 2026-09 buybacks of 103, 164 and 268 TAO; 2026-05 SDK; 2026-08 per-sample decisions. — [Subnet Alpha: Gradients](https://subnetalpha.ai/subnet/gradients/)
- [P] Weekly 2026 tournaments are evident from public artefacts, e.g., an image tournament dated 2026-10-12 and a flagged-duplicate submission repo from tourn_..._20261005. **Duplicate detection exists**; the exact method is unknown. — [HF dataset](https://huggingface.co/datasets/imagedevlopment/gradients-image-tourn_5bf35647da58489e_20261012-1149652a); [gradients-opensource duplicate repo](https://github.com/gradients-opensource/god-image-tourn-5277c96d70607ba0-20261005-dedup-5fhxn4nu-0e488912ea32b81d)
- [S, HYPE] Gradients claims about 26% better models at about 26% lower cost than TogetherAI over 16 runs, and 3,000 paying users (2025-07 interview). — [Subnet Alpha](https://subnetalpha.ai/subnet/gradients/)
- Status: **mainnet, live, weekly**.

**Ridges (SN62). Coding agents.**
- [P, checked 2026-11-05] Miners submit coding agents. These are benchmarked on "real software tasks": they inspect repos, write patches, and are scored on whether the result works. Agents that improve score or cost earn rewards "after approval". There are 3 live competitions (IDs 28 to 30: Database Query Engineering, Test Generation, Problem Solving) with emission splits of 50/25/25. The site reports **19.3K agent submissions**, "1K+ infinite benchmarks" and 12.1K Ridges alpha rewarded. Code is at github.com/ridgesai/ridges. — [ridges.ai](https://www.ridges.ai/)
- [S, 2026-10] Validators sample live open-source repos, including PyPI packages, to generate challenges and run patches in isolation. Ridges is described as winner-takes-all (dashboard dated 2026-04-29) and partnered with Latent Holdings (2026-01). — [KuCoin/OGAudit](https://www.kucoin.com/news/insight/TAO/6ad90ca1c31ba800073269d4); [Subnet guide](https://simplytao.ai/blog/your-simple-guide-to-ridges-sn62)
- Overlap: permissionless agents with validator re-execution, but the product is the *agent*, not an improvement to a shared training artefact. Status: **mainnet, live**.

**Affine (SN120). RL models.**
- [S] Miners submit models hosted on Chutes (SN64). Validators evaluate them across RL environments (WebShop, ALFWorld, SAT, SWE-Infinite and others) through "Affinetes". The winner is the **Pareto-frontier** model; a challenger must beat the champion on *all* environments. It is winner-takes-all. It claims to be "sybil-proof, decoy-proof, copy-proof, overfitting-proof" [HYPE: project claim]. — [TAO Daily](https://taodaily.io/affine-subnet-120-the-decentralized-reasoning-revolution); [Subnet Alpha: Affine](https://subnetalpha.ai/subnet/affine/)
- Overlap: king-of-the-hill model improvement with validator re-measurement. No recipe or diff lineage. Status: **mainnet, live**.

**Hone (SN5).**
- [S, mostly 2025] An ARC-AGI-2 reasoning competition run by Latent Holdings and Manifold Labs. Validators generate novel ARC-AGI-2 tasks with ARC-GEN, and the target is about 85%. No 2026 mechanism change was found. — [TAO Daily](https://taodaily.io/why-hone-subnet-5-could-be-bittensors-shot-at-real-agi); [Hone README](https://raw.githubusercontent.com/manifold-inc/hone/main/README.md)
- Overlap: low. It is a model benchmark competition, not recipe improvement.

**Macrocosmos Apex (SN1) "competitions".**
- [P, 2026] Miners submit solutions through the Apex CLI to code or policy competitions: path planning on an IOTA network simulator (2026-03), NIST peg assembly in MuJoCo with ONNX policies (v0.6.0 PR dated 2026-11-01, v0.6.1 "pre-launch fixes" 2026-11-02), and Humanoid Olympics. Validators score the submissions and set weights. — [macrocosm-os/apex-competition-nist-assembly](https://github.com/macrocosm-os/apex-competition-nist-assembly); [PR #19](https://github.com/unarbos/apex-competition-nist-assembly/pull/19); [Macrocosmos Substack](https://macrocosmosai.substack.com/p/the-iota-simulator-on-apex)
- Overlap: generic "submit code, validator scores it" competitions. Not ML training research. IOTA SN9 (collaborative pre-training, "Train at Home" since 2026-02-10) is covered in prior notes and is a training-as-work network, not a research market.

**Other Bittensor findings**

### Inferences
- Bittensor validators re-measure work, while our design adds *optimistic* challenge and slashing. This is a real architectural difference: Bittensor relies on validator stake-weighted consensus (Yuma) rather than a fraud-proof window, and miners risk only registration fees, not slashable stake.
- Teutonic's 5-king window is the only live "lineage royalty" found. It pays by recency, not by causal inclusion, which leaves the recursive, step-proportional reference reward (D-PoDL :178) unclaimed.
- The three relevant subnets each picked a different stats bar: 3-run median (Crusades), sample-level 99% bootstrap (Gradients) and LCB α = 0.001 (Teutonic). None publishes a calibrated noise floor in the way PI's 54-step finding does. This supports a "reference statistical acceptance spec" as a contribution of ours.

## Q2. Non-Bittensor projects: autoresearch ecosystem, labs, decentralized-training orgs, staking-on-models precedents, on-chain competitions, research-agent platforms, kernel leaderboards

### Takeaway
Off Bittensor, the "autoresearch" field has fragmented into dozens of open projects. The four most relevant are multiplayer swarms (Hyperspace AGI, autoresearch-at-home, ZeroThesis), git-DAG lineage research (Agora, arXiv 2609.18094), verifier-gated public leaderboards (ECDSA.Fail, OpenAI Parameter Golf, Pluralis Protocol NanoGPT), and staking precedents (Numerai Atomic Staking v3). Every multiplayer swarm either trusts self-reports (Hyperspace: "No statistical significance testing") or pays nothing. Every rigorously verified competition is centrally refereed, pays cash or nothing, and has no stake or slashing. Recall Network, the main on-chain agent-competition venue, announced its wind-down on 2026-10-30.

### Cited Findings

**Hyperspace AGI (hyperspaceai/agi). The largest "distributed autoresearch" network.**
- [P] A P2P network (libp2p GossipSub) of autonomous agents running autoresearch loops in five domains: ML val_loss, search NDCG@10, finance Sharpe, skills pass-rate and "causes". It uses five CRDT (Loro) leaderboards. Agents adopt and mutate peers' better configs, and each agent has its own branch by peer ID; branches are never merged. Compute is "verified" through pulse rounds with matrix challenges and commit-reveal, which proves liveness, not correctness. **The snapshot disclaimer reads: "Raw CRDT leaderboard state. No statistical significance testing."** Peer review is agents scoring papers 1 to 10. Rewards are **points** (for example about 44,100 points/month for an 80GB GPU). A separate "Hyperspace A1" chain (chain ID 808080, Mysticeti consensus) exists. MIT license, about 2.1k stars, 248 forks. — [hyperspaceai/agi](https://github.com/hyperspaceai/agi)
- [S, 2026-06] Repo created 2026-03-08. The project reports 660 agents and 27,247 experiments, plus 2M+ nodes and 3.6M downloads [HYPE]. Hourly snapshots stopped 2026-04-17, the last repo push was 2026-06-11, and the last chain release was v1.7.8 (2026-04-29). Points are non-tradeable, the project appears on airdrop trackers, and no token conversion has been announced. **"No published breakthrough results"**; most discussion is about points farming. — [rywalker.com](https://rywalker.com/research/hyperspace-agi)
- [S, 2026-03] An early run had 35 agents perform 333 experiments overnight (2026-03-08/09), and a Kaiming-init idea spread through gossip. — [VentureBeat](https://venturebeat.com/technology/andrej-karpathys-new-open-source-autoresearch-lets-you-run-hundreds-of-ai?amp=); [Varun Mathur on X](https://x.com/varun_mathur/status/2031004607426498574)
- Status: **live testnet/points network, partially stalled**. Verification is weak.

**autoresearch-at-home (mutable-state-inc).**
- [P] A "SETI@home-style" swarm on a shared Ensue workspace. Agents follow THINK, CLAIM (with semantic de-duplication and 15-minute expiry), RUN (5 minutes), PUBLISH (full `train.py`), and pull a global-best `train.py`. A leaderboard key exists. **No re-running or auditing of reported results, and no rewards or attribution scheme.** MIT license, 495 stars, 2026 copyright. — [autoresearch-at-home](https://github.com/mutable-state-inc/autoresearch-at-home)
- [P] A separate project, "Recursive automated AI research", reports beating the autoresearch@home community solution on NanoChat. — [recursive-org](https://github.com/recursive-org/first-steps-toward-automated-ai-research) (via [awesome-autoresearch](https://github.com/yibie/awesome-autoresearch))

**ZeroThesis (zerothesis.com). "Multiplayer autoresearch" with a ledger.**
- [P, checked 2026-11-05] Users point an agent at a skill file, and the agent self-registers and works on 97 active challenges (circle and sphere packing, Golomb rulers, Ramsey and Schur bounds, sorting networks, kissing numbers), mostly scored against records from Packomania, AlphaEvolve and OEIS. **"Every verified result is chained into a public ledger under your name."** Many challenges use exact or recomputed verification. **The page names no chain and mentions no rewards, staking or tokens.** Most challenges have one or two contributors. — [ZeroThesis](https://zerothesis.com)
- Overlap: permissionless agents, verifier-gated, attribution ledger. It works on math and combinatorics with cheap exact verifiers, not stochastic ML training, so it never faces the multi-seed noise problem.

**Agora: Git as Shared Memory for Collective AutoResearch (arXiv 2609.18094; NVIDIA-affiliated authors incl. Jan Kautz; v1 2026-09-16, v4 2026-09-30).**
- [P] Contributions are an **append-only DAG in Git**: each commit links a result, insight, hypothesis, verification or report to prior work. In about 12 days, 13 LLM workers with no planner cut a dev evaluator from 3.39 to 1.899 bpb, with 1,703 contributions and 165 verifications of 95 targets performed by non-authors ("no reported failures"). The best method's **145-commit ancestry spans 15 accounts**. No incentives are discussed. — [arXiv 2609.18094](https://arxiv.org/abs/2609.18094)
- Overlap: this is the closest published artefact to our **lineage graph**. It shows that multi-author ancestry happens in practice, but it has no credit or royalty assignment and no adversarial model.
- Not to be confused with Pluralis "Agora" (arXiv 2607.13332, pre-training), which is covered in prior notes.

**ECDSA.Fail: Open Autoresearch (arXiv 2609.09582; 35 authors incl. Jieyi Long; v1 2026-09-09).**
- [P] Humans and agents publish **evaluator-verified improvements to a public leaderboard** for reversible secp256k1 point-addition circuits (Shor's algorithm). Score S = Q×T fell 86.1% by the 2026-07-26 cutoff. No incentives are described. — [arXiv 2609.09582](https://arxiv.org/abs/2609.09582)
- [P] Related open leaderboards: the Binohash Autoresearch Challenge ("a trusted evaluator that counts each submission into a public ledger"), leanSPHINCS (draft rules for an autoresearch competition on Ethereum-account signatures), and math-autoresearch (formal proof certification before acceptance). — [awesome-autoresearch](https://github.com/yibie/awesome-autoresearch)

**Karpathy autoresearch itself and the wider ecosystem.**
- [S, 2026-06] The repo went dormant around 2026-03-26 with 86,192 stars by 2026-06 (another source: "no LICENSE file", no commits in more than two months as of a 2026-06 review). There are about 13.7k forks. **No Karpathy-endorsed token, bounty or reward program was found.** — [rywalker.com](https://rywalker.com/research/hyperspace-agi); [search summary](https://rywalker.com/research/autoresearch); [karpathy/autoresearch](https://github.com/karpathy/autoresearch)
- [P] The "awesome-autoresearch" list (checked 2026-11-05, first 100k of 230k characters read) has sections for multiplayer swarms, verified leaderboards, speedruns (autoresearch-speedrun with "a two-stage paired-seed acceptance funnel"; IntologyAI NanoGPT-Bench), kernels (AutoKernel, Kernaut) and markets (trading loops on Kalshi, Polymarket, Hyperliquid and Base DEX). **No visible entry combines verified ML results with crypto rewards.** — [awesome-autoresearch](https://github.com/yibie/awesome-autoresearch)
- [S, ~2026-04] "Agent Orchestration Protocol" (agentorchestrationprotocol.org) is a Show HN about AI CLI agents doing research tasks in a Reddit-like app and being paid in crypto. It describes no verification and names no chain; the thread is nearly empty [HYPE/low signal]. — [HN 47411158](https://news.ycombinator.com/item?id=47411158)
- [S, 2026-03-12] Nervous Machine ran hundreds of autoresearch runs on H100, GB10 and GH200 and stores findings as certainty-scored claims with CONTRADICTS links. It notes that the more than 3,300 forks don't share findings. No rewards. — [Nervous Machine Substack](https://nervousmachine.substack.com/p/3000-agents-are-running-experiments)
- [S, 2026-11-05] Applied Compute "Ari Autoresearch" is a closed commercial agent; one run lifted a Qwen3.5-9B chess-puzzle reward from 0.118 to 0.629 in 16 hours. — [FourWeekMBA](https://fourweekmba.com/ai-applied-compute-agent-lifts-chess-reward-5-3x-in-16-hours/)
- [P] NVIDIA published a "How to Run an Autoresearch Workflow with RL Agent Skills and NeMo" guide (2026). This is tooling, not a market. — [NVIDIA blog](https://developer.nvidia.com/blog/how-to-run-an-autoresearch-workflow-with-rl-agent-skills-and-nvidia-nemo/)

**Prime Intellect.**
- [P, PRs dated to 2026-08-14] frontier-automated-speedrun ran 18 models unattended on 8×H200. Its frozen `verify.py` requires 8 fixed-seed runs with mean below 3.27859 (about 1-in-1000 by luck). The leaderboard is Fable 5 at 2,726 steps, Opus 5 at 2,920 and Kimi K3 at 2,968. It is a 24-star repo, no license is shown, and **no public-submission policy or rewards** exist; it is a benchmark study. — [frontier-automated-speedrun](https://github.com/PrimeIntellect-ai/frontier-automated-speedrun); [PI blog](https://primeintellect.ai/blog/measuring-autonomous-research)
- [P/S, 2025-10 to 12] The Environments Hub bounty program pays $100–500 for open-access tasks and $1,000–5,000+ for application-only ones, with "eval based compensation". Prime Intellect reports 400+ environments from bounties and the residency, and 2,500+ community environments on the Hub. The first Hub call listed "Environments for NanoGPT speedrun optimizations". Payment is cash, decided centrally, with no stake. — [PI blog: scaling environments program](https://www.primeintellect.ai/blog/scaling-environments-program); [PI blog: Environments Hub](https://www.primeintellect.ai/blog/environments); [X @afurgs 2025-12](https://x.com/afurgs/status/1997292157212983300)
- [S, 2026-07-08] Prime Intellect raised a $130M Series A and turned toward enterprise environments and evals (prior notes). — [TechCrunch](https://techcrunch.com/2026/07/08/prime-intellect-raises-130m-series-a-to-help-enterprises-build-their-own-ai-agents/)

**Pluralis Protocol NanoGPT Speedrun (2026-09-29 to 2026-12-01).**
- [P] The task is to train a 203M model to val loss 3.276 on FineWeb with pipeline parallelism over simulated 200 Mb/s, 50 ms WAN links. Stage, transfer accounting and data-loading code are **frozen**, and the target must be hit "with statistical significance, following the modded-nanogpt test". Organizers **rerun entries that beat the current best**, and entrants get a 7-day dispute window. Prizes are $10k/$5k/$3k ($18k), paid in cash, and the page says **"No crypto, no third parties."** Submissions are MIT-published after close. Winners will be named at the CODEC-FM workshop at NeurIPS 2026. Agents are not addressed. — [Pluralis Protocol NanoGPT](https://pluralis.ai/protocol-nanogpt/)
- Overlap: frozen harness, significance test, rerun and a **dispute window**. These are our verification semantics, run centrally for cash.

**OpenAI "Model Craft Challenge: Parameter Golf" (2026-03-18 to 2026-04-30; repo still active).**
- [P] Entrants build the best FineWeb bpb model within a 16 MB artifact that trains in 10 minutes on 8×H100. New records must beat SOTA by at least 0.005 nats **with p < 0.01, typically averaged over 3 runs**. Top entries are verified over time, and non-reproducible results are disqualified. Submissions are PRs to `/records`. The prize is $1M in compute credits via a grant form, plus recruiting. 1.4k PRs, 5.2k stars, MIT license. The top record is 1.0565 bpb. — [openai/parameter-golf](https://github.com/openai/parameter-golf)
- Overlap: a frozen, statistically gated recipe competition with human and agent PRs at scale. It is centralized, the reward is not on chain, and there is no lineage credit.

**Gensyn (Judge, Delphi).**
- [P, 2025-08-27] Judge provides verifiable AI evaluation on Verde (refereed delegation: on disagreement, bisect to the diverging operator). — [Gensyn blog: Introducing Judge](https://blog.gensyn.ai/introducing-judge/)
- [P/S, 2026-04] Delphi is an AI-settled information/prediction market. Two frontier models review evidence, and an open judge model in Gensyn's Reproducible Execution Environment (REE) makes the final call. Gensyn concedes that receipts prove the computation, not that "every source or market definition was correct". ### Inferences
- **Two disjoint clusters exist and nobody bridges them.** Cluster A is rigorous but centralized: Parameter Golf, Pluralis Protocol NanoGPT, PI frontier-automated-speedrun, GPU MODE, ECDSA.Fail. These have frozen harnesses, significance tests, reruns and even dispute windows, but pay cash or nothing. Cluster B is decentralized but weakly verified: Hyperspace, autoresearch-at-home, Agent Orchestration Protocol. These are permissionless agent swarms with self-reported results and points. Bittensor subnets sit in between: validator re-measurement and emissions, but no slashing or fraud proofs, and lineage credit is shallow at best.
- Numerai is the only mature system where participants **stake on their own claimed performance and get burned**. Its MMC is a working marginal-contribution reward. Both carry over directly to "stake on your diff; royalties by marginal contribution to the current record".
- Recall's wind-down (2026-10-30) and Hyperspace's stalled archive (2026-04) are evidence that token- or points-led agent competitions without durable verified output struggle. This supports a credibility-first, testnet-first positioning.

### Inferences
- **Uniquely ours**, as far as these searches show (2026-11-05):
  1. An **optimistic dispute layer for stochastic training claims**: stake, then challenge window, then bisection to a step, then committee replay on a pinned stack, then slash. Gensyn has the bisection primitive (Verde) but no research market. Bittensor has markets but no fraud proofs.
  2. **Recursive lineage royalties by causal inclusion.** Teutonic pays the last 5 kings flat. Numerai's MMC pays marginal contribution to an ensemble. Agora records ancestry but pays nothing. A royalty that flows along the diff DAG to every ancestor a record includes, weighted by measured marginal gain (e.g., ablation or Shapley-style), was not found anywhere.
  3. A **published, frozen, hash-committed acceptance spec with a measured noise floor**: k seeds, α, minimum effect, and calibration on heterogeneous rented GPUs. Each competitor picks ad-hoc thresholds, and Teutonic changed δ mid-run (2026-07-21).
  4. **Chain-agnostic, L2-settled reference implementation with an explicit threat model.** Every live competitor is either Bittensor-locked or centralized.
- **Competitive risk:** Teutonic or Gradients could add slashing or longer lineage windows cheaply; Pluralis, OpenAI or PI could add on-chain prizes; Gensyn could launch a Delphi-style "research market" on REE. None has announced this (no evidence found). The window is open but probably months, not years; this is an inference.
- **Practical implications:** port Teutonic's paired bootstrap LCB and Gradients' per-sample bootstrap into the verifier, Crusades' timelock commit-reveal and weight verification into submission, Numerai's clip-and-burn plus MMC into the economics, and Agora's commit-DAG format into lineage. Then publish a cross-system comparison as part of the paper, positioned as the neutral reference.
